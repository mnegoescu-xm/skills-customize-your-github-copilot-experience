
# 📘 Assignment: Games in Python — Hangman

## 🎯 Objective

Build a playable Hangman game in Python that lets a player guess letters to discover a hidden word. Focus on string handling, loops, conditionals, and clear user interaction.

## 📝 Tasks

### 🛠️	Build the Hangman core

#### Description
Implement the core Hangman gameplay as a terminal program. The player should be able to repeatedly guess letters until they either discover the word or run out of attempts.

#### Requirements
Completed program should:

- Randomly select a secret word from a predefined list
- Prompt the player to guess a single letter at a time
- Reveal correctly guessed letters in the word (for example: _ a _ _ a _)
- Display the number of incorrect guesses remaining
- Prevent repeated penalties for letters that were already guessed
- End the game with a clear win or lose message
- Provide a simple text-based UI suitable for the terminal


### 🛠️	Optional: Enhancements

#### Description
Add one or more optional features to improve gameplay or user experience.

#### Requirements
Completed program may include any of the following:

- Load words from an external file or a larger word list
- Support difficulty levels (easy / medium / hard) that affect word length or attempts
- Keep score across multiple rounds and allow replay
- Show simple ASCII-art that progresses with incorrect guesses
